# MeditateNow

A simple meditation timer app for Android written in Kotlin, built as a learning project.

## Features

- [ ] Countdown timer with customizable session length
- [ ] Start/pause/reset controls
- [ ] Ambient background sounds during sessions
- [ ] Session history / streak tracking
- [ ] Daily reminder notifications
